Where this comes from

Every number on these four tabs is read through blitsen/os, a native module with no web equivalent. A browser tab cannot ask what the processor is called, how much memory is installed, or what is mounted — the closest the web platform comes is navigator.hardwareConcurrency, one deliberately coarsened number.

The displays are the one thing not read here: those are window.monitors(), which already reports each monitor's size, position and scale factor.
