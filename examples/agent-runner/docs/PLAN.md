agency-runner allows you to connect agent files with local clis via a slick and simple interface.

Setting up:
Step 1: Pick an agent root folder that contains the **/**/file.md structure for your agents. Folders are navigatable in the app and hot reloaded on local changes.

Executing an agent:
Step 1: Choose a folder -> agent
Step 2: Fill out the execution context
Step 3: Choose a CLI from a list of installed CLIs (codex or claude)
Step 4: Click run. This will launch a terminal with the agent and context.
